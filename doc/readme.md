# DNS RFC 文档

本目录存放 dnsd 实现所依据的 DNS 相关 RFC 原文, 全部来自 IETF 官方发布站点,
供离线查阅. 每个文件均附官方下载链接, 便于核对或更新为最新文本.

## 文件列表

- **[rfc1034.txt](https://www.rfc-editor.org/rfc/rfc1034.txt)**: Domain names - concepts and facilities
- **[rfc1035.txt](https://www.rfc-editor.org/rfc/rfc1035.txt)**: Domain names - implementation and specification
- **[rfc2181.txt](https://www.rfc-editor.org/rfc/rfc2181.txt)**: Clarifications to the DNS Specification
- **[rfc2308.txt](https://www.rfc-editor.org/rfc/rfc2308.txt)**: Negative Caching of DNS Queries (DNS NCACHE)
- **[rfc2782.txt](https://www.rfc-editor.org/rfc/rfc2782.txt)**: A DNS RR for specifying the location of services (DNS SRV)
- **[rfc3596.txt](https://www.rfc-editor.org/rfc/rfc3596.txt)**: DNS Extensions to Support IP Version 6
- **[rfc4343.txt](https://www.rfc-editor.org/rfc/rfc4343.txt)**: Domain Name System (DNS) Case Insensitivity Clarification
- **[rfc6891.txt](https://www.rfc-editor.org/rfc/rfc6891.txt)**: Extension Mechanisms for DNS (EDNS(0))
- **[rfc7766.txt](https://www.rfc-editor.org/rfc/rfc7766.txt)**: DNS Transport over TCP - Implementation Requirements
